# Archived examples

These files are preserved as historical recipes and regression references, but
are no longer the recommended entry points for new users.

Use the canonical examples instead:

- progressive tutorials: `examples/tutorials/`;
- complete scientific cases: `examples/cases/`;
- reusable API recipes: `examples/python/`.

The archived Qi Hu scripts predate the canonical case at
`examples/cases/qi_hu/`. They remain useful when comparing the literal JSON
construction with the object-first implementation.
